# Décisions d'architecture

Une décision par fichier, numérotée, jamais réécrite : si une décision est
remise en cause, on en ajoute une nouvelle qui remplace l'ancienne.

Format : contexte, décision, conséquences (y compris celles qu'on n'aime pas).

Écrire une ADR quand un choix sera difficile à comprendre dans six mois sans
explication — pas pour chaque dépendance ajoutée.
